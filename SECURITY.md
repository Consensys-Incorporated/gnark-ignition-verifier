# Security Policy

This repository is part of the gnark ecosystem. Security issues in this
repository are handled according to the
[gnark security policy](https://github.com/Consensys/gnark/blob/master/SECURITY.md).

## Reporting a Security Bug

Please report security bugs by email to
[gnark-security-report@consensys.com](mailto:gnark-security-report@consensys.com).

Your email will be acknowledged within 7 days, and you'll be kept up to date
with the progress until resolution. Your issue will be fixed or made public
within 90 days.

For all other details — issue tracks (PUBLIC, PRIVATE, URGENT), the
disclosure process, and how to receive security announcements — refer to the
[gnark security policy](https://github.com/Consensys/gnark/blob/master/SECURITY.md).
